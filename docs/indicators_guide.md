# 📊 المؤشرات الفنية — الدليل الشامل

## 🔵 1. RSI — Relative Strength Index
### مؤشر القوة النسبية

**إيه هو؟**
مؤشر بيقيس قوة حركة السهم من 0 إلى 100. بيوضح إذا كان السهم "متشبع شراء" (Overbought) أو "متشبع بيع" (Oversold).

**إزاي بنقراه؟**

| القيمة | الحالة | المعنى |
|--------|--------|--------|
| **أقل من 30** | Oversold | السهم انخفض بشدة — احتمال ارتداد صعودي |
| **30 - 70** | محايد | الوضع الطبيعي |
| **أكثر من 70** | Overbought | السهم ارتفع بشدة — احتمال تصحيح |
| **أكثر من 80** | مبالغ فيه | **البوت يرفض الشراء** |

**البوت بيستخدمه إزاي؟**
- **الشراء:** RSI بين **40 و 70** (منطقة صحية)
- **الرفض:** RSI > 80 (مبالغ في الارتفاع)
- **القوة:** RSI 50-60 = الأفضل (توازن بين القوة والاحتياط)

**مثال من رسائلك:**
```
ETEL — RSI: 58 ✅ (منطقة صحية)
```

**نصيحة:** RSI < 30 مع اتجاه صاعد = فرصة ممتازة (يسمى "Pullback").
RSI > 80 مع اتجاه هابط = فخ (احتمال انعكاس قوي).

## 🔵 2. EMA — Exponential Moving Average
### المتوسط المتحرك الأسي

**إيه هو؟**
متوسط سعر السهم خلال فترة، مع ترجيح أكبر للأسعار الحديثة. (بعكس SMA اللي بيعطي نفس الوزن لكل الأسعار).

**الأنواع:**

| النوع | الفترة | الاستخدام |
|-------|-------|-----------|
| **EMA25** | 25 شمعة | الاتجاه قصير المدى (Short-Term) |
| **EMA50** | 50 شمعة | الاتجاه متوسط المدى |
| **EMA200** | 200 شمعة | الاتجاه طويل المدى (Trend) |

**إزاي بنقراه؟**
- **السعر فوق EMA50:** اتجاه صاعد (Bullish) ✅
- **السعر تحت EMA50:** اتجاه هابط (Bearish) ❌
- **EMA50 فوق EMA200:** اتجاه صاعد قوي (Golden Cross) ✅✅
- **EMA50 تحت EMA200:** اتجاه هابط قوي (Death Cross) ❌❌

**البوت بيستخدمه إزاي؟**
- **الشراء:** السعر فوق EMA50 + EMA50 فوق EMA200
- **الرفض:** EMA50 < EMA200 (اتجاه هابط)
- **البونص:** EMA50 أعلى بكثير من EMA200 (اتجاه قوي)

**مثال من رسائلك:**
```
ETEL — EMA50: 138.50 | EMA200: 125.20 ✅
→ السعر 146.80 > EMA50 > EMA200
→ اتجاه صاعد قوي
```

**نصيحة:** السعر فوق EMA200 = الاستثمار فيه فرصة.
السعر تحت EMA200 = الانتظار أفضل.

## 🔵 3. ATR — Average True Range
### المدى الحقيقي المتوسط

**إيه هو؟**
مؤشر بيقيس **تقلب** السهم (Volatility) — يعني بيقولك السهم بيتحرك كام في اليوم.

**إزاي بنقراه؟**
- **ATR مرتفع:** السهم متقلب — فرص ومخاطر أعلى
- **ATR منخفض:** السهم هادئ — حركة بطيئة

**البوت بيستخدمه إزاي؟**
- **حساب Stop Loss:** `stop = entry - (ATR × 2.5)` — يعني الستوب بعيد عن السعر بمقدار 2.5 ضعف التقلب اليومي
- **حساب الأهداف:** كل هدف = Entry + (ATR × مضاعف)
- **حماية من التقلبات:** لو ATR مرتفع، الستوب يبعد أكتر

**مثال من رسائلك:**
```
ETEL — سعر: 146.80 | ATR: 5.87
Stop Loss = 146.80 - (5.87 × 2.5) = 132.12 ✅
```

**نصيحة:** ATR % = (ATR / Price) × 100
- ATR < 1% = هادئ جدًا (نادر)
- ATR 1-2% = طبيعي
- ATR 2-4% = متقلب
- ATR > 4% = عالي جدًا (مضاربة)

## 🔵 4. ADX — Average Directional Index
### مؤشر قوة الاتجاه

**إيه هو؟**
مؤشر بيقيس **قوة الاتجاه** (صاعد أو هابط) — **مش الاتجاه نفسه**، بل قوته.

**إزاي بنقراه؟**

| القيمة | القوة | المعنى |
|--------|-------|--------|
| **0-20** | ضعيف | السوق عرضي (Range-bound) |
| **20-25** | ضعيف-متوسط | اتجاه بدأ يظهر |
| **25-40** | قوي | اتجاه صاعد/هابط |
| **40-60** | قوي جدًا | اتجاه قوي |
| **> 60** | مبالغ فيه | احتمال انعكاس |

**البوت بيستخدمه إزاي؟**
- **الفلترة:** ADX ≥ 25 (اتجاه قوي — إجباري)
- **البونص:** ADX > 40 = +10 نقاط
- **الرفض:** ADX < 25 (مفيش اتجاه واضح)

**مثال من رسائلك:**
```
ETEL — ADX: 32 ✅ (اتجاه قوي)
```

**نصيحة:** ADX < 20 + RSI محايد = السوق عرضي، تجنبه.
ADX > 40 + EMA متوافقة = اتجاه قوي، فرصة ممتازة.

## 🔵 5. MACD — Moving Average Convergence Divergence
### تقارب وتباعد المتوسطات

**إيه هو؟**
مؤشر بيتابع العلاقة بين EMA(12) و EMA(26) — وبيساعد في تحديد **الزخم (Momentum)**.

**مكوناته:**
- **MACD Line:** EMA(12) - EMA(26)
- **Signal Line:** EMA(9) للـ MACD Line
- **Histogram:** MACD - Signal

**إزاي بنقراه؟**

| الحالة | الإشارة |
|--------|---------|
| **MACD > Signal** | زخم صاعد (Bullish) ✅ |
| **MACD < Signal** | زخم هابط (Bearish) ❌ |
| **MACD يقطع Signal لفوق** | إشارة شراء ✅✅ |
| **MACD يقطع Signal لتحت** | إشارة بيع ❌❌ |
| **MACD > 0** | الزخم إيجابي |

**البوت بيستخدمه إزاي؟**
- **الشراء:** MACD > Signal (زخم إيجابي)
- **الرفض:** MACD < Signal (زخم سلبي)
- **القوة:** MACD > 0 (فوق خط الصفر)

**مثال من رسائلك:**
```
ETEL — MACD: 1.5 > Signal: 1.0 ✅ (زخم صاعد)
```

**نصيحة:** MACD بطيء في إشاراته — استخدمه **للتأكيد** مش للتوقيت.
مع RSI: RSI يعطي إشارة أسرع، MACD يؤكد.

## 🔵 6. Stochastic — المذبذب العشوائي
### مؤشر الزخم اللحظي

**إيه هو؟**
مؤشر بيقيس مكان السعر الحالي مقارنة بأعلى وأدنى سعر خلال فترة. من 0 إلى 100.

**مكوناته:**
- **%K:** المؤشر الأساسي (سريع)
- **%D:** متوسط %K (بطيء)

**إزاي بنقراه؟**

| القيمة | الحالة |
|--------|--------|
| **> 80** | Overbought (تشبع شراء) |
| **< 20** | Oversold (تشبع بيع) |
| **20-80** | المنطقة الطبيعية |

**البوت بيستخدمه إزاي؟**
- **الرفض:** Stoch > 80 (تشبع شراء)
- **الشراء:** Stoch < 80 (منطقة طبيعية)

**مثال من رسائلك:**
```
ETEL — Stoch: 65 ✅ (منطقة طبيعية)
```

**الفرق بين RSI و Stochastic؟**
- **RSI:** أبطأ، يشوف 14 فترة سابقة
- **Stochastic:** أسرع، يركز على الوضع الحالي

البوت بيستخدم الاتنين للتأكيد المتبادل.

## 🔵 7. RVOL — Relative Volume
### الحجم النسبي

**إيه هو؟**
مقارنة حجم تداول السهم **الآن** بمتوسط حجمه خلال آخر 20 يوم.

**إزاي بنقراه؟**

| القيمة | التفسير |
|--------|---------|
| **< 0.5x** | حجم منخفض — اهتمام ضعيف |
| **0.5x - 1.0x** | حجم عادي |
| **1.0x - 1.5x** | حجم مرتفع قليلاً |
| **1.5x - 2.0x** | اهتمام واضح ✅ |
| **> 2.0x** | اهتمام قوي جدًا ✅✅ |

**البوت بيستخدمه إزاي؟**
- **الشراء:** RVOL ≥ 1.2 (اهتمام مرتفع)
- **البونص:** RVOL ≥ 2.0 = Super Breakout
- **الرفض:** RVOL < 1.0 (مفيش اهتمام)

**مثال من رسائلك:**
```
ETEL — RVOL: 1.8x ✅ (اهتمام واضح)
```

**نصيحة:** RVOL هو **أقوى مؤشر للصدق**:
- ارتفاع السعر + RVOL عالي = **اتجاه حقيقي** ✅
- ارتفاع السعر + RVOL منخفض = **فخ** ❌
