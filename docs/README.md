## كلمات مفتاحية متكررة

| عربي | إنجليزي | المعنى المختصر |
|------|---------|----------------|
| سهم | Stock / Share | وحدة ملكية في شركة |
| مؤشر | Indicator | مقياس رياضي لحالة السهم |
| اتجاه | Trend | حركة السعر العامة (صاعد/هابط/عرضي) |
| دعم | Support | مستوى سعري يتوقف عنده الهبوط |
| مقاومة | Resistance | مستوى سعري يتوقف عنده الصعود |
| اختراق | Breakout | تجاوز مستوى مقاومة |
| تصحيح | Correction | هبوط مؤقت بعد صعود |
| مخاطرة | Risk | احتمال الخسارة |
| عائد | Return | الربح المحقق |
| تنويع | Diversification | توزيع الاستثمار لتقليل المخاطرة |
| سيولة | Liquidity | سهولة بيع/شراء السهم |
| عمولة | Commission | رسوم السمسرة |
| انزلاق | Slippage | فرق السعر بين المتوقع والمنفذ |
| دمغة | Stamp Duty | ضريبة على البيع |
